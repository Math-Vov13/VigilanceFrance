Important pour la production :

  Les secrets doivent maintenant être configurés via kubectl :
  kubectl create secret generic vigilance-secrets \
    --from-literal=GOOGLE_CLIENT_ID='your_real_client_id' \
    --from-literal=GOOGLE_CLIENT_SECRET='your_real_client_secret' \
    --namespace=vigilance-france

  Ou bien modifier directement le fichier k8s/base/secrets.yaml localement (sans le
  committer) avant de le déployer.
